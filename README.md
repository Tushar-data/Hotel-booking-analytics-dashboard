# Hotel Performance Analytics Dashboard

Project Overview

This project analyzes hotel booking data to evaluate revenue performance, booking trends, guest behavior, cancellation patterns, room-type performance, and payment preferences.

The project follows an end-to-end data analytics workflow where the dataset was taken from Excel, cleaned and analyzed using Python, and transformed into an interactive Power BI dashboard for business insights.

Dataset Overview

The dataset contains hotel booking and guest information, including booking status, hotel details, room types, payment methods, revenue, guests, stay duration, and cancellation information.

Key Data Fields

* Hotel Name
* Booking Date
* Room Type
* Payment Mode
* Booking Status
* Revenue
* Guests
* Nights
* City
* Cancellation Status

Tools & Technologies

* Excel – Dataset and initial data source
* Python – Data cleaning, preprocessing and exploratory data analysis
* Pandas – Data manipulation and analysis
* NumPy – Numerical operations
* Matplotlib – Exploratory visualization
* Power BI – Interactive dashboard and business intelligence
* DAX – KPI calculations and analytical measures

Data Cleaning & Preparation

Python was used to prepare the raw hotel booking data for analysis.

Key steps included:

* Handling missing values
* Removing duplicate records
* Checking and correcting data types
* Cleaning inconsistent data
* Creating analytical columns
* Performing exploratory data analysis
* Preparing the cleaned dataset for Power BI
